# 校园失物招领智能匹配平台

《软件测试与质量保证》课程原创项目。校园里东西丢了/捡到了，在平台上登记一条信息，
系统会用**文本相似度 + 类别 + 地点 + 日期新鲜度**自动算出最可能配对的记录（Top3 推荐带匹配度%），
还能开**私聊留言**窗口直接联系对方。

## 功能

- 📝 **发布登记**：丢东西 / 捡到东西都能登记（物品、类别、地点、描述、联系方式）
- 🔍 **智能匹配**：TF-IDF 文本相似度(70) + 类别一致(20) + 地点重合(10) + 日期新鲜度(5)，Top3 带星级
- ✨ **关键词高亮**：匹配页自动标绿双方描述中重合的词
- 💬 **私聊留言**：每条记录一个留言窗口，2 秒自动刷新
- ✅ **状态标记**：找回/认领后标记，不再参与匹配
- 🛡 **无匹配兜底**：没匹配到时提示联系保卫处调取监控
- 🔒 **联系方式脱敏**：列表页 138****0042，详情页完整

## 快速开始

```bash
pip install -r requirements.txt
python app.py            # 打开 http://127.0.0.1:5000
python test_matcher.py   # 运行匹配算法自动化测试，生成 测试报告.md
```

## 项目结构

```
├── app.py            Flask 应用（路由 + 页面）
├── matcher.py        智能匹配算法
├── test_matcher.py   匹配算法自动化质量测试
├── data/items.json   失物/拾获数据
├── templates/        页面模板（Jinja2）
├── static/style.css  样式
└── 测试报告.md        test_matcher.py 生成的测试报告
```

## 自动化测试

`test_matcher.py` 对匹配算法做了 4 类测试：

| 类型 | 示例 |
| --- | --- |
| 准确率 | 已知配对（蓝牙耳机丢失 ↔ 拾获）断言排 Top1 |
| 边界 | 空标题+空描述不崩溃；单字描述“卡”能命中校园卡 |
| 不变性 | 描述加感叹号/空格，匹配分波动 ≤5 |
| 排序稳定性 | 加入干扰记录后正确配对仍排 Top1 |
